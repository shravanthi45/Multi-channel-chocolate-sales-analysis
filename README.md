Multi-Channel Chocolate Sales Analytics Dashboard (Excel)

🧾 Project Overview
This project presents an interactive Excel dashboard designed to analyze chocolate sales across multiple channels, customer segments, and time periods. The dashboard provides deep insights into sales performance, purchase behavior, and transaction success rates.

---

🎯 Objective
To build a dynamic dashboard that:
- Tracks multi-channel sales performance
- Analyzes customer purchase behavior
- Identifies top-performing products and roles
- Monitors transaction success rates
- Supports data-driven business decisions


📁 Dataset
The dataset includes:
- 📅 Date (Year-wise filtering: 2023, 2024)
- 🛒 Purchase Mode (App, Website, In-store, Phone)
- 💰 Purchase Amount
- 🔢 Transaction Count
- ✅ Successful Transactions
- 📦 Product Categories
- 👨‍💼 Job Titles (Customer segmentation)

⚙️ Process

1. Data Cleaning
- Removed null/blank values
- Standardized category names
- Ensured consistent formatting

2. Data Preparation
- Created structured tables
- Added calculated fields:
  - Success %
  - Total Transactions
  - Aggregated Sales

3. Data Analysis
- Built Pivot Tables for:
  - Channel-wise analysis
  - Product performance
  - Job role segmentation
  - Monthly trends

4. Dashboard Creation
- Combined multiple visuals into one interactive dashboard
- Added slicers for:
  - Year
  - Purchase Mode
  - Product

---

📊 Dashboard Features

- 📈 **Daily/Monthly Sales Trend Line Chart**
- 📊 **Channel-wise Sales & Transactions Analysis**
- 📦 **Product Performance Breakdown**
- 👨‍💼 **Customer Segmentation by Job Role**
- 📉 **Success Rate (%) Visualization**
- 🎛 **Interactive Filters (Slicers)**

---

🔍 Key Insights

- 🌐 Website & App channels generate highest revenue
- 🏬 In-store purchases show stable transaction success rates
- 📱 Phone orders have lower volume but consistent performance
- 👨‍💼 Certain job roles (e.g., Professionals, Engineers) contribute more to sales
- 🍫 Specific chocolate products dominate revenue contribution
- 📊 Overall transaction success rate is above 70% across channels

💡 Conclusion

The dashboard reveals that:
- Digital channels (App & Website) are key revenue drivers
- Targeting high-value customer segments can boost sales
- Product-level optimization can improve profitability
- Monitoring success rates helps improve operational efficiency

🚀 Tools Used
- Microsoft Excel
  - Pivot Tables
  - Pivot Charts
  - Slicers
  - Conditional Formatting
